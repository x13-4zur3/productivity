# Journal, tasks, and focus

Start on **Home** to see due and overdue tasks, recent journal activity, your latest reflection, and a writing prompt. You can swap the prompt or open it in a new entry.

## Write a journal entry

1. Open **Journal** and write an entry.
2. Choose a mood such as `:D`, `:|`, `:(`, or `<3` and add tags if you want to group related entries.
3. Save the entry. Use search, mood, or tags to find it later.

In **1.1.0**, select text in a saved entry and choose **Create task**. The new task includes a link to the journal entry it came from.

## Schedule a task

1. Open **To-do** and enter a task name.
2. Expand **Due date, priority, repeat** to schedule it or make it repeat.
3. Save the task. Expand its row to add subtasks.

Use filters to see completed or open tasks. When you complete a recurring task, Productivity creates its next occurrence with its subtasks unchecked. Open **Reminders** to see tasks due today or overdue. If desktop reminders are available on your device, enable them and keep the To-do view open to receive them.

In **1.1.0**, plan deadlines in the [Calendar and Weekly planner](calendar.md). To recover a deleted entry, task, subtask, or event, choose **Undo** in the notification within 30 seconds.

## Search across your workspace

In **1.1.0**, use **Ctrl+F** on Windows or Linux or **Command+F** on macOS to open the Search sidebar. Press the same keys again to close it. Filter by Journal, Tasks, or Events, or use **All types** to search everything together. The sidebar stays open as you move between pages.

## Start a focus session

Choose **5**, **15**, or **25 minutes** in the focus timer and start it. The footer shows the countdown as you switch pages. Pause, resume, or reset at any time. The timer remembers its state when you reopen Productivity.

In **1.1.0**, choose **Custom**, enter a duration from 1 to 180 minutes, and select **Start focus**. The main button switches to **Pause**, **Resume**, or **Start again** as the session progresses. Select the timer in the footer to return to it from any page, even while it’s paused.

## Personalize the app

Open **Settings** above the theme picker in the desktop sidebar.

| Section | What you can change |
| --- | --- |
| General | Display name and start page |
| Appearance | Docs, Docs Dark, Terminal, or High Contrast theme and reduced motion. Pink is available in 1.1.0. |
| Shortcuts | Assign a combination, clear a shortcut, or restore its default |
| Account | Connect, switch accounts, sign out, or use local data |

| Default shortcut | Windows and Linux | macOS |
| --- | --- | --- |
| Open Settings | Ctrl + , | Command + , |
| Save an entry or task | Ctrl + Enter | Command + Enter |
| Dismiss a confirmation | Esc | Esc |

To change a shortcut, select its binding, press the new combination, then choose **Save changes**. To delete an entry, task, or subtask, confirm the in-app dialog.

## Use the Windows title bar

In **1.1.0**, drag the themed title bar to move the window. Double-click the title area to maximize or restore. The buttons on the right minimize, maximize or restore, and close the window.
