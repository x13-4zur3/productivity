# Calendar and weekly planner

Calendar and Weekly planner are part of **Productivity 1.1.0**. If you sign in, the account service needs the 1.1.0 server code too. [Release status](changes.md#productivity-110)

## Choose a calendar view

| View | What you see | Keyboard navigation when a date has focus |
| --- | --- | --- |
| **Month** | A month grid with color-coded markers for events, task deadlines, and journal entries | Left or Right moves by day. Up or Down moves by week. |
| **Linear** | One Monday-to-Sunday week with items you can open directly | Up or Down moves by day. Left or Right moves by week. |

Both views keep the date you selected. The previous and next buttons move by month or week, depending on the view. **Today** jumps back to today.

## Plan a day

1. Select a date to see its **Selected day** agenda. Open an item to view the task or journal entry, or edit the event.
2. Choose **Add event** to schedule something for the selected date. Leave both time fields empty for an all-day event. A start and end date can span multiple days.
3. Choose **Add task for this day** to create a task with that date prefilled.

## Review the week

Open **To-do list → Weekly planner**. Review scheduled, overdue, and unscheduled tasks. Choose a new due date for a task or move it to today from the planner.

The Linear calendar includes events and journal entries alongside tasks. Use Weekly planner when you want to reschedule several tasks.
